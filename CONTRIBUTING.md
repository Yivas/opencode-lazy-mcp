# Contributing

This repository currently contains project documentation, not an OpenCode plugin. Documentation
corrections and scoped proposals are welcome through
[issues](https://github.com/Yivas/opencode-lazy-mcp/issues) and pull requests. Discuss a runtime
design before starting implementation work.

Search existing issues first. For a documentation problem, include the file or link, what it says,
and what should change. For a proposal, include the exact OpenCode version or revision, the public
plugin or MCP API involved, and the user-visible behavior. No software baseline is supported yet; do
not report untested compatibility as established behavior.

Keep each pull request focused. Explain the reason, list the files changed, check relative links,
and identify the checks actually run. There are no build or test commands in this scaffold. Do not
add package manifests, generated output, workflows or installation claims just to fill space.

Remove credentials, private endpoints, personal paths, MCP server configuration with real values,
conversations, prompts and session logs from all submissions. Send sensitive findings through
[SECURITY.md](SECURITY.md). Participation follows the [Code of Conduct](CODE_OF_CONDUCT.md).
Contributions are made under the repository's [MIT License](LICENSE); retain notices required by any
authorized source material.
